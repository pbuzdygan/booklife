[`@zxing/browser` 0.2.1](https://github.com/zxing-js/browser) distribution under

[`@zxing/library` 0.23.0](https://github.com/zxing-js/library) code under the

browser does not provide native EAN-13 detection. Booklife does not load this
code from a third-party service while it is being used.
