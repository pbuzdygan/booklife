# Booklife branding assets

The PNG variants are generated from that source for these uses:

- `16`, `32`, and `48` px: browser/favicon sizes;
- `180` px: Apple Touch Icon;
- `192` and `512` px: installed PWA icons;
- `booklife-favicon.ico`: multi-size fallback favicon containing 16, 32, and 48 px variants.

Copies used by the application are in `catalog/static/catalog/icons/`. Keep the
two folders in sync whenever the source mark changes.
