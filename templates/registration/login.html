First time using Booklife?

A new installation starts with username booklife and temporary password booklife.

Change that public password immediately from the folder containing compose.yaml:

docker compose run --rm web python manage.py changepassword booklife

The container logs repeat these credentials and the command. Existing databases never receive or reset this account automatically.
